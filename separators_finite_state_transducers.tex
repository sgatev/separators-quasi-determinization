\chapter{Separators in finite-state transducers}
\label{chapter:separators_finite_state_transducers}

In this chapter, we present separated finite-state transducers. We study the special
case when the relation recognized by such devices is a function of bounded variation
and describe an efficient deterministic representation for it. It is decidable
whether the relation represented by a finite-state transducer is a function of
bounded variation \cite{beal} so the described constructions are effective.
